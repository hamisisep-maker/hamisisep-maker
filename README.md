# Hi, I'm Hamisi 👋

Building **Hamzone Technologies** — AI evaluation infrastructure, human-in-the-loop
testing, and applied AI/geospatial intelligence products.

- 🧪 **Hamzone AI Training** — a human-evaluation platform where paid Kenyan
  taskers and reviewers red-team, adversarially test, and validate AI systems
  through an independent Task → Submission → Review → Finding pipeline.
- 🚦 **Hamzone Road Safety AI** — Kenyan blackspot detection and driver-warning
  intelligence, starting deterministic and rules-based before any machine
  learning gets near a real driver warning.
- ☕ **Hamzone EUDR Compliance** — coffee traceability and EU deforestation
  regulation compliance tooling for Kenyan cooperatives and exporters.
- 🧱 **P2Less** — the shared infrastructure layer underneath all of it: APIs,
  auth, messaging, and integrations.

Most of what I build lives in private repos — client and production work, not
open source by default.
